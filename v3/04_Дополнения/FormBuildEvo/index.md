# FormBuildEvo

## Установка
Модуль для понижения порога входа в работу с формами в Evolution CMS.

Для раскрытия потенциала модуля необходимы:
`DocLister` - База
`FormLister` - Отправка форм в Evolution
`FormSender` - Отправка форм в Evolution AJAX (Считается основой в рамках этого модуля)

Выполните команды из директории `/core`:
1. Установка пакета
```
php artisan package:installrequire kolya1222/formbuildevo "*"
```
2. Публикация стилей и скриптов
```
php artisan vendor:publish --provider="Kolya1222\Formbuild\FormbuildServiceProvider"
```
3. Выполните миграции
```
php artisan migrate
```

## Как пользоваться

Заходите в административную панель и переходите в раздел Модули, где у вас появится новый раздел: `Formbuild module`
При переходе в модуль вас встретит _всплывающим окном подсказки_ в котором описан базовый алгоритм, предупреждения и горячие клавиши.

### Составление формы

Далее вам необходимо составить саму форму используя любой удобный вам способ:

1. Drag and Drop.
2. Кнопка `Добавить поле`.
3. Горячие клавиши.

При необходимости укажите параметры создаваемого поля указанные в форме. 
Не переживайте **все базовые необходиммые поля конструктор заполнит сам**
Поля можно менять местами между собой при помощи Drag and Drop, если вам это потребуется

### Общие настройки

Далее переходите к `Настройкам формы` при их изменении **необходимо нажать кнопку** `Сгенерировтать` для внесения изменений в генерацию

Укажите уникальный `ID формы`.
Выберите оставлять `Форма отправляется без перезагрузки` для работы через `FormSender` (Рекомендуется в 9 из 10 случаев)
При снятии чекбокса модуль будет использовать внутрений алгоритм генерации для `FormLister`
Остальные общие поля заполняйте по мере необходимости все остальное конструктор сгенерирует автоматически.

### Создание шаблона Письма

В модуле, есть возможность формирования шаблона письма приходящего к вам на почту в верхней части конструктора.
В нем присутствует возможность перетаскивания существующих полей в ващей форме в шаблон письма.
После необходимо нажать кнопку сохранить шаблон чтобы шаблон пременился.

#### Использование созданной формы

Теперь необходимо работать с блоком Результат

1. Скопируйте созданный `HTML` и разместите его в шаблоне.
2. Перейдите в раздел `FormLister/Sender` нажмите кнопку создать файл.
3. Проверьте наличие скрипта `FormSender` на странице.

##### Дополнительно

В модуле присутсвует возможность сохранения и загрузки ранее созданых форм интерфейс которых находиться в правой верхней части модуля.
Модуль практически полностью работает на JS и состоит из 10 основных файлов:

1. **Main.js** - инициализация, глобальные функции, управление tooltip, обработка кастомного select
2. **render-form.js** - формирование результатов:
   - `htmlOutput` - HTML разметка
   - `paramsOutput` - PHP код
   - `previewOutput` - демонстрация формы
   - обработка статусов и валидации
3. **FormSettings.js** - модальное окно настроек поля
4. **drag-drop.js** - логика перетаскивания полей
5. **control-field.js** - работа с полями (добавление, удаление, создание, tooltip)
6. **file-generation** – отвечает за отправку в контроллер запроса на создание файла для FormSender.
7. **form-utils** – общие для сохранения и загрузки функции и показ уведомлений теперь находится тут.
8. **load-form** – логика для загрузки формы в рабочую область.
9. **save-form** – отправка запроса на сохранение формы в контроллер.
10. **email-template** - редактор reportTpl для составления шаблона письма.
